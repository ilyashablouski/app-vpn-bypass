# vpn-bypass

Скрипт для исключения доменов, IP и приложений из VPN (например, Urban VPN Desktop) на macOS и Linux.

## Как работает

VPN-клиент перенаправляет весь трафик в туннель. Скрипт добавляет в таблицу маршрутов
более точные маршруты (`/32`) на IP исключений через ваш обычный шлюз (роутер).
Более точный маршрут побеждает default-маршрут VPN, и трафик идёт напрямую.

## Использование

1. Впишите исключения в `bypass.conf` (домены, IP/подсети, `app:Имя`).
2. Включите Urban VPN, затем:

```bash
chmod +x vpn-bypass.sh
sudo ./vpn-bypass.sh watch    # держит маршруты актуальными; Ctrl+C - остановить и очистить
sudo ./vpn-bypass.sh apply    # разовое применение
sudo ./vpn-bypass.sh status   # что добавлено
sudo ./vpn-bypass.sh clear    # убрать всё
```

Переменные окружения: `BYPASS_CONFIG`, `BYPASS_INTERVAL` (сек, по умолчанию 30),
`BYPASS_GATEWAY` / `BYPASS_IFACE` (если шлюз не определился автоматически).

## Ограничения

- Применяйте после включения VPN: если VPN переподключится и сбросит маршруты, `watch` вернёт их за интервал.
- Домены с CDN меняют IP, поэтому нужен `watch`. Поддомены нужно перечислять явно.
- Приложения определяются по их текущим соединениям (`lsof`), а не на уровне ОС: первые соединения
  после запуска приложения могут пойти через VPN. Для приложений надёжнее вписывать их домены.
- Только IPv4. Если VPN-клиент блокирует изменение маршрутов или использует DNS/IPv6-перехват, часть
  трафика может всё равно идти через VPN. Встроенный split tunneling клиента (если есть) надёжнее.
- Windows не поддерживается (там аналог: `route add <IP> mask 255.255.255.255 <шлюз>`).

## GUI для macOS

В папке `gui/` лежит приложение на Python/tkinter: статус Urban VPN, кнопка запуска и остановки
исключений, добавление доменов, IP и приложений (`.app`).

```bash
python3 gui/app.py
```

Нужен `python3` с tkinter (на macOS: `brew install python-tk`, если его нет).

- Запуск и остановка скрипта идут через системный запрос пароля администратора.
- Если Urban VPN выключен (нет default-маршрута через `utun*`), запустить исключения нельзя.
- Приложение читает и пишет `bypass.conf`. Запущенный `watch` подхватывает изменения сам.
- Лог скрипта: `/tmp/vpn-bypass.log`.
- Тесты логики: `cd gui && python3 -m unittest discover -s tests`.
