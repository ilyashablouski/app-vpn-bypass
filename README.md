# vpn-bypass

Нативное приложение для macOS (SwiftUI), которое исключает выбранные домены, IP и приложения
из VPN (например, Urban VPN Desktop). Для остального трафика VPN продолжает работать.

## Как работает

VPN-клиент перенаправляет весь трафик в туннель (`utun*`). Приложение добавляет в таблицу маршрутов
более точные маршруты (`/32`) на IP исключений через обычный шлюз (`en*`). Более точный маршрут
побеждает default-маршрут VPN, и трафик идёт напрямую.

Возможности: иконка в строке меню, окно настроек, автозапуск при входе в систему. Исключения
останавливаются автоматически при отключении VPN и возобновляются при повторном подключении
(можно отключить).

## Устройство (папка `macos/`)

- `VPNBypass.app` (SwiftUI, `MenuBarExtra`) и привилегированный демон `VPNBypassHelper` (root, XPC).
  Пароль вводить не нужно: helper один раз подтверждается в Системных настройках.
- Без дочерних процессов: маршруты через PF_ROUTE сокет, таблица маршрутов через `sysctl`,
  DNS через `getaddrinfo`, соединения приложений через libproc. Состояние VPN определяется по событиям
  PF_ROUTE, а не опросом.
- Для приложений сопоставляются и их вспомогательные процессы (по пути к `.app`).
- Маршруты удалённых из списка записей убираются автоматически (diff-синхронизация).

## Сборка

Нужен Xcode, macOS 14+.

```bash
cd macos
swift test                                              # тесты
SIGN_ID="Apple Development: Имя (TEAMID)" ./build.sh    # результат: macos/build/VPNBypass.app
```

Скопируйте приложение в `/Applications`, запустите, нажмите «Установить helper» и подтвердите его
в Системных настройках -> Основные -> Объекты входа.

Список исключений из старого формата (`bypass.conf`: домен, IP или подсеть, `app:Имя`, комментарии
после `#`) импортируется кнопкой «Импорт bypass.conf…» в настройках.

## Ограничения

- `SMAppService` требует подписанное приложение (Apple Development или Developer ID); при подписи
  ad-hoc helper может не зарегистрироваться.
- Для строгой привязки XPC добавьте Team ID в `Constants.clientRequirement`.
- Только IPv4. Поддомены нужно перечислять явно (`*.` в начале отбрасывается).
- Приложения определяются по уже открытым соединениям, поэтому первые соединения после запуска
  приложения могут пойти через VPN. Надёжнее вписывать их домены.
- Если VPN-клиент перехватывает DNS или перезаписывает маршруты, часть трафика может идти через VPN.
- Не проверено на реальном Urban VPN.
